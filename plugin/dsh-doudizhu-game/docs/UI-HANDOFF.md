# 斗地主插件 UI 交接文档（给 grokbot）

用途：重做界面视觉 / 布局时，这份文档说明**现有界面有哪些东西、每个东西显示什么数据、点了会干什么**。
功能逻辑已经跑通，重设计只改「看」的部分，不要改状态机和动作逻辑。

- 插件目录：仓库内的 `plugin/dsh-doudizhu-game`
- 源文件：`src/ui.js`（组件）、`src/style.js`（CSS 字符串）、`src/i18n.js`（中英文案）、`src/game.js`（规则）、`src/engine.js`（七档出牌引擎）
- 构建：`node build.mjs` → 生成 `client.js`；装到 `~/.dsh/plugins/dsh-doudizhu-game/client.js` 后**重启 DSH** 才生效（插件是启动时内嵌加载，没有热更新）

---

## 0. 三个屏幕

| 屏幕 | 何时出现 | 内容 |
|---|---|---|
| 开局设置 `setup` | 进入插件、或结算点「换挡再战」 | 玩法选择（叫分 / 抢地主）、三家难度下拉、开始、帮助、战绩 |
| **牌桌 `table`**（本文重点） | 点「开始新一局」后 | 见下面分区 |
| 弹层 | 按需盖在牌桌上 | 叫分 / 加倍 / 明牌确认 / 认输确认 / 结算 / 复盘 / 帮助 |

牌桌是整页（主区槽 `main`），没有滚动条以外的固定侧栏；窄屏（<720px）走手机断点。

## 1. 牌桌从下到上的分区

```
┌───────────────────────────────────────────────────────────┐
│ topbar：斗地主  [叫分·pro9999 拉满]   🂠记牌器 托管 👁明牌 ♪ English ? 返回 │
├───────────────────────────────────────────────────────────┤
│ counterbar（记牌器，默认收起，点顶栏 🂠 展开）：            │
│  3×1  4×1  5×1  6×1  7×1  8×1  9×1  10×3  J×1  Q×1  K×1  A×1  2×1  小×1  大×0 │
├───────────────────────────────────────────────────────────┤
│ seatrow：        [上家 seat2]      [回合提示 pill]      [下家 seat1]        │
├───────────────────────────────────────────────────────────┤
│ mid（桌面中央）：                                           │
│   「桌上这手牌 / 还没人出牌」                                │
│   上一手打出的牌（小牌面，静态，留到下一手）                 │
│   思考中转圈：「pro500 思考中…」                             │
├───────────────────────────────────────────────────────────┤
│ bottom：                                                   │
│   [我的座位 seat0：头像 我 · 剩17张 · 倒计时环]              │
│   手牌 17 张（一排，可按住滑动多选，选中的抬起）            │
│   手牌信息：「轮到你出牌 · 已选 2 张」                       │
│   按钮第一行：取消  不出  出牌(主按钮)                       │
│   按钮第二行：提示  问军师  托管  认输(红)                   │
│   建议卡：右下角悬浮（问军师 / 托管时有内容）                 │
└───────────────────────────────────────────────────────────┘
```

### 1.1 顶栏 `ddz-topbar`

| 元素 | 显示 | 点击 |
|---|---|---|
| 标题 `ddz-title` | 「斗地主」+ 小字 `叫分 · pro9999`（玩法 · 我的难度） | — |
| 🂠 记牌器 `ddz-chipbtn` | 展开/收起记牌器 | 切换 counterbar |
| 托管 `ddz-chipbtn` | 关/开（开时高亮 `is-on`） | 开：AI 替我出牌；再点交还控制 |
| 👁 明牌 ×2 | 只在出牌/加倍阶段、且我没明牌时显示 | 弹确认，确认后倍数×2，座位上出现「明牌」标 |
| ♪ | 音效开/关（开时高亮） | 静音切换 |
| English | 文案语言 | 切中/英（记住） |
| ? | 帮助 | 打开帮助弹层 |
| 返回 | 回到开局设置 | 当前局丢弃（有确认？无，直接回） |

### 1.2 记牌器 `ddz-counterbar`

- 每个点数一格 `ddz-count`：`rank × 剩余张数`，横排换行。
- 3…10、J Q K A、2、小王、大王 共 15 格。
- 「剩余」= 外面还没露面的张数 = 4 − 我手里的 − 已经打出的（大小王各 1 张）。
- 状态类：`is-hot`（还剩 1 张，重点提醒）、`is-zero`（出光了，变灰）。
- 花色颜色：♥♦ 红、♠♣ 黑。

### 1.3 三家座位 `Seat`

- 座位号：**0 = 我（下方）**，1 = 下家（右），2 = 上家（左）；出牌顺序 0 → 1 → 2。
- 每个座位显示：头像 `ddz-avatar`（24px 圆）、名字、地主冠 `♛` + 「地主」标（`landlord-tag`）、明牌标（`open-tag`）、`剩 N 张`、叫分/加倍信息（`×2` 之类）。
- 轮到谁：座位加 `is-turn` 类（高亮边框/呼吸）；**只有我自己**有倒计时环 `ddz-ring`（SVG 圆环 + 秒数，30 秒走完）。
- 出牌动作时，该座位旁可显示「不出」标记；我这边用牌桌中央的提示代替。

### 1.4 牌桌中央 `ddz-mid`

- `ddz-turnpill`：叫分阶段「轮到 X 叫分」、加倍阶段「三家选加倍」、出牌阶段「地主是 X」。
- `ddz-lastlabel` + `ddz-played`：上一手牌（小牌面 `ddz-card small static`），**保留到下一手**；没人出过显示「还没人出牌」。
- `ddz-think`：AI 思考时转圈 + 「pro500 思考中…」，AI 落子后消失。
- 叫分 / 加倍弹层盖在牌桌中间（不是全屏遮罩），因为需要看着自己的牌决定。

### 1.5 手牌 `Hand`

- 一排牌，从小到排（3 4 5 … 2 小王 大王）；牌面显示点数 + 花色（♥♦ 红色）。
- **选中方式：按住鼠标/手指横向滑动**，经过的牌切换选中（不是单击）。选中的牌向上抬起、边框高亮。
- 禁用态 `disabled`（不是我的回合 / 托管中）：整排半透明、不能选。
- 手牌信息行：轮到我时「轮到你出牌」（托管时「托管中」），否则「pro200 思考中…」；右侧「已选 N 张」。
- 出牌前会校验：必须是自己手里的牌、是合法牌型、压得过桌上（或领出）、不能剩 1 张。

### 1.6 操作按钮 `ddz-actions`

第一行（主操作）：

| 按钮 | 文案 | 何时可点 | 行为 |
|---|---|---|---|
| 取消 | `取消` | 一直 | 清空选中的牌 |
| 不出 | `不出` | 轮到我 且 是跟牌（桌上有人出、且不是我） | 过牌；两家连过则新一轮由上一手出牌者领出 |
| 出牌 | `出牌`（主色） | 轮到我、未托管 | 校验通过后出牌；不合法给 toast 并保留选中 |

第二行（辅助）：

| 按钮 | 文案 | 行为 |
|---|---|---|
| 提示 | `提示` | 循环给出可出的牌型：第一次出最小能压的，再点换下一个，选不中就清空 |
| 问军师 | `问军师` | 按**我的难度档**算一手建议，显示在建议卡（出什么 + 为什么 + 估计胜率） |
| 托管 | `托管` / `托管中` | 开关 AI 代打；托管时每次轮到我，AI 出牌理由会留在建议卡上 |
| 认输 | `认输`（红） | 二次确认后结束本局（算输，照常结算） |

### 1.7 建议卡 `ddz-advice`（右下角悬浮）

字段：

| 字段 | 含义 | 示例 |
|---|---|---|
| 标题 | 「军师建议」 | — |
| 出牌 | 具体牌面 + 牌型名 | `单张 7`、`对子 9`、`三带一 666+3` |
| 理由 | 一句话解释（引擎给） | 「地主只剩 1 张，必须压住」 |
| 胜率 | 估计胜率（高难档才算） | 「估计胜率 63%」 |
| 采纳 | 按钮：把这手牌自动选中 | 点完选中对应牌，用户再点「出牌」 |

### 1.8 弹层

| 弹层 | 内容 | 按钮 |
|---|---|---|
| 叫分 `bidPanel` | 当前叫分最高值、我的分值选项（叫分模式：不叫/1/2/3；抢地主模式：叫地主/不叫/抢地主） | 点一个即提交，AI 决定用弹层里的「思考中」占位 |
| 加倍 `doublePanel` | 叫/抢结束后三家同时选：不加倍 / 加倍 ×2 / 超级加倍 ×4 | 同上 |
| 明牌确认 | 提示倍数翻倍（×2 / 明牌后 ×2） | 确认 / 取消 |
| 认输确认 | 「确定认输？」 | 确认 / 取消 |
| 结算 `Result` | 赢/输标题、倍数明细（底分、加倍、明牌、炸弹、春天/反春）、三家各自得分（赢家 +，输家 −）、用时 | 再来一局 / 换挡再战 / 看复盘 / 关闭 |
| 复盘 `Replay` | 一步步翻：发牌 → 叫分 → 加倍 → 每手出牌/过牌，显示谁出了什么、剩几张 | 上一步 / 下一步 |
| 帮助 `Help` | 规则、玩法、快捷键说明 | 关闭 |

toast：短提示（非法出牌、识别失败、托管开关等），右下角浮出 2 秒。

## 2. 状态与数据（只读约定）

`st`（游戏状态）：

| 字段 | 类型 | 含义 |
|---|---|---|
| `mode` | `'score' \| 'rob'` | 叫分 / 抢地主 |
| `phase` | `bid → double → play → over`（另有 `redeal` 三家不叫重发） | 阶段 |
| `hands` | `[counts, counts, counts]` | 三家手牌，长度 15 的计数数组 |
| `bottom` | `counts` | 3 张底牌 |
| `landlord` | 0/1/2/-1 | 地主座位 |
| `bidHigh` / `bidHighSeat` / `bidLog` | 数字/座位/记录 | 叫分情况 |
| `doubling` / `doubleChosen` | `[1,1,1]` / `[bool,bool,bool]` | 加倍倍数、是否已选 |
| `open` | `[bool,bool,bool]` | 谁明牌 |
| `bombs` | 数字 | 炸弹/王炸次数（每次 ×2） |
| `turn` | 0/1/2 | 轮到谁 |
| `last` | `{seat, move} \| null` | 桌上上一手（null = 新轮领出） |
| `passes` | 0/1/2 | 连续过牌数 |
| `playCounts` | `[n,n,n]` | 各家出牌手数（判春天用） |
| `winners` | `'landlord' \| 'farmers' \| null` | 谁赢 |
| `result` | 对象 | 结算（见下） |
| `replay` | 数组 | 复盘记录 |
| `tiers` | `['go','go','go']` | 三家难度 |

牌面模型：点数 `3..15`（=3..2），`16` 小王，`17` 大王；计数数组下标 = 点数 − 3。

结算 `result`：`{ landlordWon, winners, scores:[n,n,n], multiplier, base, spring, antiSpring, bombs, seconds, doublings:[..], open:[..] }`。

派生函数（`G.*`）可直接用来显示：`G.seatCounts(st)`、`G.bidSeat(st)`、`G.bidOptions(st)`、`G.legalMoves(st,seat)`、`G.hintList(st,seat)`、`G.aiMove(st,seat)`。

## 3. 动作（点了要调用它们，别自己写规则）

| 动作 | 调用 | 说明 |
|---|---|---|
| 开始新一局 | `startGame()` | 用当前 tiers 发牌 |
| 叫分/抢地主 | `userBid(v)` | v：叫分 0/1/2/3；抢地主 `'call'/'rob'/0` |
| 加倍 | `userDouble(v)` | 1 / 2 / 4 |
| 明牌 | `userOpen()` | 有确认弹层 |
| 出牌 | `userPlay()` | 校验 + 出牌 + 推进 |
| 不出 | `userPass()` | |
| 提示 | `userHint()` | 循环 |
| 问军师 | `askAdvice()` | 30ms 后出结果（高难档几百 ms） |
| 托管 | `setAuto(v)` | 开关 |
| 认输 | `userSurrender()` | 直接结束 |
| 选中牌 | `setSel(prev => …)` | `{cardId: true}` |
| 换语言 | `setLang / setView` | localStorage 记住 |

快捷键（已写进代码，待重建验证）：轮到出牌时 **空格 = 提示、回车 = 出牌、Esc = 取消**；输入框内不拦。

计时：轮到人 **30 秒**，超时自动过牌或出最小一手；AI 思考延时约 0.5–0.7 秒（高难档更久，因为引擎真在推演）。

## 4. 样式与文案

- 所有样式都在 `src/style.js` 的 CSS 字符串里，插件用 `#dsh-doudizhu-styles` 注入；类名统一 `ddz-` 前缀。改样式只改这一个文件，别改 `ui.js` 的结构除非要加元素。
- CSS 变量（深色为主，`prefers-color-scheme: light` 有浅色覆盖）：
  `--ddz-bg --ddz-panel --ddz-panel-solid --ddz-line --ddz-line-strong --ddz-text --ddz-dim --ddz-accent --ddz-accent-weak --ddz-good --ddz-bad --ddz-gold --ddz-felt --ddz-card-bg --ddz-card-ink --ddz-red`
- 所有中文文案在 `src/i18n.js` 的 `zh`，英文在 `en`；组件里只写 `T.xxx`，不要硬写中文（否则英文模式漏字）。
- 关键文案 key：`start/help/modeScore/modeRob/myTier/downTier/upTier/counter/auto/autoOn/open/passAction/playAction/hint/advice/cancel/surrender/yourTurn/thinking/selectToast/lastPlay/noPlay/landlordIs/bidTurn/doubleTurn/scoreLine/again/reTier/replay/stepPrev/stepNext/tierNames.*`

## 5. 重设计时请保留的行为（测试在守）

`node test/render.test.mjs` 会检查：

1. 插件三处注册（main / sidebar.panellist / sidebar.panellist.actions），「更多」里一行能打开面板；
2. 开局面板有标题、开始按钮、三个难度下拉各 7 档；
3. 开局后牌桌出现：手牌恰好 17 张、记牌器、三个座位；
4. 托管能自动打完一整局并弹出结算，结算里有「本局得分」「再来一局」，点「再来一局」回到牌桌；
5. 战绩写进 localStorage。

`node test/game.test.mjs` 守规则（发牌、叫分、加倍、出牌、过牌、结算、春天/反春、明牌翻倍）。
`node test/check-keys.mjs` 守文案与 API 名字没写错。

改完必须：`node build.mjs && node test/game.test.mjs && node test/render.test.mjs && node test/check-keys.mjs`。
